# Survival40 Auto

WordPress automation plugin for Survival40.

## Current baseline
- WordPress article generation with Gemini
- SEO metadata support
- reference/source blocks
- internal-link routing
- homepage problem-based navigation
- real-use product blocks
- affiliate-link hooks
- responsive homepage layout

## Development policy
From this repository onward, the repository is the source of truth.
Do not manage development by exchanging ad-hoc ZIP versions.

## Long-term target
Fully automated media operation:

topic selection -> keyword selection -> article generation -> product discovery ->
affiliate link generation -> internal links -> SEO -> publish -> performance feedback

Manual intervention should be exceptional, not part of the normal publishing flow.
