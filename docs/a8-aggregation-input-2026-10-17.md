# A8 成果データの安全な取り込み準備（2026-10-17）

> 本資料と `scripts/analytics/a8_csv_audit.py` は**隔離PRの試作**。本番サイト、広告、A8アカウント、GA4設定は変更しない。CSVの定期取得、メール監視、成果通知や自動案件差し替えは現時点で**未稼働**。

## 根拠・読み取り条件

- A8.net公式: 2026年6月、**成果別（発生）/ 確定（成果別）CSV・Excelにサイト名列追加**。https://a8pr.jp/2026/06/16/report_update/
- A8.net公式: 成果発生・未確定・確定・キャンセルは別の状態。広告クリック数にはクリック課金型の成果が含まれうる一方、一般的な**成果発生件数には含まれない**。https://support.a8.net/a8/as/faq/2025/post_2611.html
- A8.net公式: 新レポートでは「確定レポート」は確定日基準、それ以外は原則発生日基準。新旧画面間は集計方法が違う場合あり。https://support.a8.net/a8/as/faq/2026/post_2792.html
- A8.net公式: 成果が発生しても報酬確定とは限らない。https://www.a8.net/campus/affiliate-dictionary/conversion.html

## 実装範囲

`a8_csv_audit.py` は**成果別（発生）CSVの１時点のスナップショット**を読み取り、正確なサイト名に一致する行だけについて、ステータス別「行数」と「指定した報酬列の合計（円）」を返す。注文ID、注文者の属性、個々の金額、URL、リファラを表示・保存しない。外部への通信や認証なし。UTF-8 (BOM可) と CP932 CSV のみに対応し、Excel形式は拒否する。

- ヘッダーは、公開ヘルプの用語を参考にした初期値 `サイト名`、`ステータス種別`、`成果報酬額`。**実際の出力CSVのヘッダーは未確認**なので、異なる場合は `--site-field`、`--status-field`、`--reward-field` で実物に一致させる。認識できないステータスや金額、サイト名列欠落の場合は計算を止める。
- `confirmed_reward_yen_in_export` は**選択した報酬列について確定ステータスの行を加算した参考値**。銀行入金・確定レポートの金額と同義ではない。金額列が「発生報酬額」か「確定金額」かによって意味が変わるので、選択時に列の定義を確認する。
- 一度のCSVの「行数」は案件の成果行であり、訪問者数・購入者の人数・広告クリックではない。期間指定はCSV本体では検証できないため、A8管理画面のダウンロード条件を別途記録する。
- 定期スナップショットの再取得で前回行と同じ結果が含まれるので、**ファイルごとの合算を新規発生とみなさない**。別の確定レポートとの足し算も禁止する。後日承認・キャンセルでステータスが変わる。
- 現時点でA8メディア会員向けの**正規の自動レポート取得手段を未確認**。別サービス向けの広告主APIをメディア会員の成果取得APIと取り違えない。資格情報をハードコードしたスクレイピング、セッションの再利用、自動クリックは行わない。
- 公開リポジトリに実CSV、注文情報、A8ログイン情報、実集計値をコミットしない。

## オフラインでの利用（実データをGitHubに入れない）

```bash
python3 scripts/analytics/a8_csv_audit.py \
  --csv /private/path/a8_occurrence.csv \
  --site '40代からの生存戦略'
```

ヘッダーが異なる場合は指定して読み直す。集計結果はJSON。結果を本番の記事・広告に自動反映することは**実装していない**。

## 次の許可された工程

1. A8実CSVの実ヘッダー・報酬列と公式の期間指定を所有者または認証済みA8コネクタで検証する。データを公開GitHubへ転送しない。
2. 正規の閲覧API/レポート配信/サポート済み連携が存在し、利用規約と必要な許諾が確認できた場合のみ、**読み取り専用**の収益結果取得を実装する。直接取得できなければ自動取得は未解決と明記する。
3. GA4の`sourceMedium`とA8の広告成果を週単位で並べて観察するが、期間が一致しても**セッション→購入の因果/個人別CVRは作らない**。GA4プロパティがUTC表示の場合は日本時間のA8と日付境界に注意する。
4. 生データや詳細注文情報をWordPress記事やSNSに露出しない。広告提携や記事の既存コード変更は別PRでレビュー・テストして判断する。
