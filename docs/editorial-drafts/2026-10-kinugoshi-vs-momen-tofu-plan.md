## 記事の冒頭案

寒くなってきたから、今夜は鍋にしよう。スーパーで豆腐を手に取ると、隣に「木綿」と「絹ごし」が並んでいる。いつも何となく選んでいないだろうか。

実は、二つの豆腐には作り方の違いがある。木綿は一度固めた豆乳を崩して布を敷いた型に入れ、重しをかけて水を抜く。一方、絹ごしは豆乳をそのまま均一に固める製法だ。**絹でこしているから絹ごし、というわけではない**。

この違いが食感・扱いやすさ・料理との相性につながる。まずは、鍋での選び方を整理しよう。

## 読者向けの比較

| 迷った場面 | 選び方の目安 | 理由 |
| --- | --- | --- |
| 寄せ鍋・水炊き | 絹でも木綿でも可 | とろっとした口当たりが好きなら絹、崩れにくさなら木綿 |
| 湯豆腐 | 絹ごしが定番。ただし木綿も可 | なめらかな食感を楽しみたい場合 |
| すき焼き | 木綿・焼き豆腐が定番 | 形を保ちやすく、しっかりした食感 |
| 麻婆豆腐 | 絹・木綿のどちらも選択肢 | 絹ならなめらか、木綿なら扱いやすく食べ応え |
| 豆腐ステーキ・炒り豆腐 | 木綿が扱いやすい | 水切りと加熱調理がしやすい |
| 冷奴・汁物 | 好みに応じて | なめらかさなら絹。風味や歯応えなら木綿 |

## 栄養の意外な違い

文部科学省「日本食品標準成分表（八訂）増補2023年」掲載の可食部100g当たり。

| 項目 | 木綿 | 絹ごし |
| --- | ---: | ---: |
| エネルギー | 73kcal | 56kcal |
| たんぱく質 | 7.0g | 5.3g |
| 水分 | 85.9g | 88.5g |
| 脂質 | 4.9g | 3.5g |
| カルシウム | 93mg | 75mg |
| カリウム | 110mg | 150mg |

木綿は一般的に水切りしているため、同じ100gでたんぱく質や脂質などが多い傾向がある。絹ごしの方がカリウムが多い値も見られる。**栄養価の優劣を一言で決めない**。製造方法・商品・凝固剤によって数値は変わりうる。
